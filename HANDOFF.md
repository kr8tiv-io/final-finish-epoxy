## Site status

The new website was briefly taken live on finalfinishepoxy.ca. The go-live could not be completed, and access to the domain was then revoked, so KR8TIV cannot run testing on the finished site on the live domain. The tested, finished version is the staging site below. finalfinishepoxy.ca still serves the Squarespace site. Going live needs domain and DNS access restored. Post-launch testing would happen then.

## Going online: two options

**Option A: restore domain access.** Log in to the domain registrar or DNS provider, then give KR8TIV access (kr8tiv@kr8tiv.io) or send the current DNS records. KR8TIV points the domain at the finished site and runs post-launch testing.

**Option B: any web developer.** Download 06 Website Files from the release, upload everything (including the hidden .htaccess) to a web host, point finalfinishepoxy.ca and www at that host with HTTPS, then submit the sitemap in Google Search Console and test. The README in 06 Website Files gives the same steps.
