Final Finish fonts

These are the two fonts used on the website.

  Cormorant Garamond   Headlines. Medium (500) in capitals.
                       Italic (400) for the cobalt accent words.
  Manrope              Everything else: body text, buttons, labels.
                       Regular (400) for text, SemiBold (600) for small capitals
                       with wide letter spacing, Bold (700) to ExtraBold (800) for emphasis.

Both files are variable fonts: one file holds every weight.
Cormorant Garamond: weights 300 to 700, plus a separate italic file.
Manrope: weights 200 to 800.

Install
  Windows: right-click each .ttf file, then Install for all users.
  Mac: double-click each .ttf file, then Install Font.
  Canva: Brand Kit, then Upload a font (Pro plan).
  Then pick the weight from the font menu (Medium, SemiBold and so on).
  Older apps that don't list the weights can use the static files from Google Fonts:
  https://fonts.google.com/specimen/Manrope and
  https://fonts.google.com/specimen/Cormorant+Garamond (Get font, Download all).
