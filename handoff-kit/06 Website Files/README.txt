WHAT THIS IS
The finished Final Finish website as plain static files (HTML, CSS, JavaScript, images, video).
No database and no server-side code. It runs on almost any web host.
This copy is set up for the live domain: www.finalfinishepoxy.ca
- robots.txt allows search engines.
- .htaccess (Apache) sends finalfinishepoxy.ca to www.finalfinishepoxy.ca, redirects the old
  Squarespace addresses (/home, /blog and the three blog posts) to the matching new pages,
  serves the clean page addresses (/services, /projects ...), and sets security headers.
- Every page names www.finalfinishepoxy.ca as its main (canonical) address.

HOW TO PUBLISH
1. Upload everything in this folder, including the hidden .htaccess file, to the web root of the host
   (often public_html).
2. On an Apache host (most shared hosting), nothing else is needed. On another server (nginx, Netlify,
   Cloudflare Pages, etc.), copy the redirects and headers from .htaccess into that host's own settings.
3. In the domain's DNS settings, point finalfinishepoxy.ca and www.finalfinishepoxy.ca at the new host,
   and turn on HTTPS.
4. Check: the homepage, a service page, a town page, a guide under /resources/, the quote form,
   and that /home and /blog redirect.
5. In Google Search Console, submit https://www.finalfinishepoxy.ca/sitemap.xml.
6. Confirm the website link on the Google Business Profile.
